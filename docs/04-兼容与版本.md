# 04 · 兼容与版本

## 版本矩阵

| 你的环境 | 能不能用 | 说明 |
|---|---|---|
| Minecraft **1.21.6**（Fabric / Paper / 原版服务端） | ✅ | `pack_format` **81** |
| Minecraft 1.21.5 及更早（`pack_format` ≥ 48） | 装得上，但**没验过** | `supported_formats` 写的是 48–82（区间内游戏不拦），本包只对 1.21.6 做过真机验收 |
| 比 1.21.6 新（`pack_format` ≤ 82） | 装得上，但**没验过** | 同上 |
| `pack_format` > 82 的新版本 | ❌ | 游戏会判版本不符 |
| 单人存档 / 服务器 | ✅ 都行 | 服务器放 `world/datapacks/` |
| Bedrock（基岩版） | ❌ | 本包是 Java 版数据包 |

## 变体

**本包只有一个变体**：`doom.ui-v2.0-beta.zip`。没有"默认 / 实验性"之分，也不需要开任何实验性玩法。

（对比：同作者的数据包 `doom.nats` 有默认与实验性两个变体 —— 那是那个包的需要。doom.ui 这里只有一个。）

## 依赖

| 依赖 | 版本 | 缺了会怎样 |
|---|---|---|
| [doom.schedule](https://github.com/DoomDecapitator/doom.schedule) | **v2+** | **不报错**，但 alert / flash / actionbar 淡出的延迟回调**静默不发生** —— 这是最常见的"装了没反应" |

本包与 `doom.nats`、`doom.log` 互不冲突，可以同时装（不同命名空间）。

## 版本号怎么读

- `v2.0-beta` —— 主版本.次版本 加一个 `-beta` 后缀：功能面已定稿、还在公测。
- 附件名与 tag 都带完整版本号（`doom.ui-v2.0-beta.zip` / tag `v2.0-beta`），**别用不带版本号的旧文件**。
- GitHub 页面上的 Pre-release 标记表示：可以装进存档玩，**但请先备份存档**。

## 升级 / 降级

1. 停服（或单人退出世界）。
2. 删掉旧的 `datapacks/doom.ui/`，放进新的 `doom.ui/`。
3. `/reload`。

包内不写世界数据文件，替换文件夹即可；`doom.ui:ctx` / `doom.ui:mixer` 两个 storage 会跨 `/reload` 保留，
想彻底清干净用 `/function doom.ui:__unload__`（或在换包前 `silent_clear_all`）。

> 跨大版本升级前**备份存档**。Beta 期间数据结构（storage 的字段名）不承诺向下兼容。

## 卸载

删掉 `datapacks/doom.ui/` → `/reload`。本包不接原版房规（不改 gamerule、不动刷怪），卸载后世界回到原样。
唯一残留：每个玩家一条 `dt.uid` 计分板分数 —— 有界无害，成因见 [CHANGELOG](../CHANGELOG.md) 的 F-8。

## 性能边界（什么时候该少用）

空载机上实测的并发阶梯（每人 30 个 UI 槽同时被驱动）：

| 同时在服人数 | 满载 TPS | 命令链截断 | 正确性 |
|---|---|---|---|
| 10 | 19.96 | 0 | 全绿 |
| 20 | 19.99 | 0 | 全绿 |
| 30 | 20.25 | 0 | 全绿 |
| 40 | ≈12.4 – 13.9 | 0 | 全绿 |
| 60 | ≈8.9 | 0 | 全绿 |

拐点在 **20–40 人之间**，瓶颈是 countdown（40 人时 TPS 增量 **−7.51**，actionbar −0.58、bossbar −1.01、xpbar ≈0）。
四十人以上建议少用长倒计时、多用一次性 actionbar。数字出处与复现口径见 [CHANGELOG](../CHANGELOG.md)。
